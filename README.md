# Michael Palmer Portfolio

Personal portfolio website for Michael Palmer, focused on computer science, AI engineering, automotive technology, software development, and engineering simulation.

## Live site

https://mpalmer79.github.io/

## V1 structure

- `index.html` contains the complete site structure and portfolio content.
- `styles.css` contains the responsive visual system and layout.
- `script.js` contains mobile navigation, scroll behavior, reveal effects, and automatic copyright year handling.

## Featured work

- Automotive Retail Performance Intelligence (ARPI)
- Vehicle Thermal Management Simulation (VTMS)
- LedgerLens
- SignalFlow
- Civil Engineer AI
- ShipDay

## Design goals

- Fast static deployment through GitHub Pages
- Responsive desktop and mobile layout
- Clear recruiter and hiring-manager scan path
- Strong separation between professional experience, technical skills, academic work, and project evidence
- Accessible navigation and reduced-motion support
- No backend or database dependency for the portfolio itself
