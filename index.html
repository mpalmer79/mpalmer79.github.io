About

Domain experience meets engineering.

My background spans automotive retail leadership, dealership systems, technical training, AI deployment, and computer science. That combination shapes how I approach software: start with the real business or engineering problem, define the system boundary, make the data trustworthy, and build the smallest architecture that can solve it well.

I am completing my Computer Science degree at Southern New Hampshire University while building portfolio systems that demonstrate software engineering, data modeling, API design, AI governance, validation, and technical communication. My strongest work sits where software must interact with a complex real-world domain.
